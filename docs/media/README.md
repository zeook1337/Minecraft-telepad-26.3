# Publication images

- `telepad-in-game.png`: the supplied screenshot of the current mod, 1920×1080.
- `curseforge-logo.png`: a 400×400 square crop centered on the telepad, also used
  as the in-mod `src/main/resources/logo.png`.
- `logo-provenance.json`: source-file hash, crop coordinates and export settings.

The screenshot was re-encoded without embedded metadata. The logo was cropped
and resized with Lanczos sampling. No AI generation, retouching, added text or
changes to the depicted scene were used. The platform and textures shown are
the actual in-game content; the texture artwork has separate provenance in
`../art/`.
